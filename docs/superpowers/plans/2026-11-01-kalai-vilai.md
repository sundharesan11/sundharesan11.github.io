# Kalai and Vilai Implementation Plan

**Goal:** Two public thought pages, inviting conversation without implying active programmes.

**Approved design:** A printed manifesto with notebook details. Identical format, heavy sans-serif wordmarks, a continuous graphic line, margin notes, and short first-person writing. Kalai uses near-black/yellow; Vilai uses warm paper/deep blue. Only Kalai and Vilai in the top navigation. Quiet links from the personal site and back via founder credit.

**Architecture:** Markdown content collection, one shared standalone Astro layout, two explicit routes. Reuse existing fonts and path helper. Scoped CSS uses tokens added to global @theme; no portfolio chrome, theme-storage scripts, or new dependencies. Native links work without JavaScript; progressive CSS view transitions respect reduced motion. Contact is a visible email link with a page-specific subject.
